Starter stacks by hardware

Chat: Qwen2.5 0.5B/1.5B or Llama 3.2 1B (quantized). Speech input: Whisper tiny/base or Vosk Hindi. Speech output: Windows SAPI or Piper. RAG: MiniLM or multilingual-e5-small.

i5 8th gen / 16GB

Try 1.5B–4B quantized chat/coding models; Whisper base/small; Kokoro/Piper TTS. 7B may load with aggressive quantization but expect CPU latency.

Upgrade / 32GB + 12GB VRAM

Consider 7B–14B quantized models, vision models around 3B–8B, faster STT and local embeddings. Exact fit depends on context length, quantization, runtime, and GPU architecture.

Cloud/API

Use hosted models when quality or speed matters more than offline privacy. API access, pricing, limits, and internet are provider-dependent; this directory does not imply a free tier.

How to read the estimates

Model parameter count is not the same as RAM usage. Actual memory depends on quantization, context length, runtime, KV cache, and whether weights are offloaded to a GPU. Speech and embedding models use different memory patterns from chat LLMs. Follow each model card for license, supported languages, and current files before installing.

Directory is a curated starting point, not an exhaustive list of every model ever released. Fit labels are rough planning estimates, not benchmark guarantees. Always verify the official model card, license, hardware requirements, and safety considerations. No external JavaScript libraries are used.
