Suggested starting stack for your voice assistant

  1. Chat brain: Qwen3-0.6B or Qwen3-1.7B GGUF Q4; test both on your actual PC.
  2. Hindi speech input: Whisper tiny multilingual or a lightweight faster-whisper configuration; test noisy Hindi/Hinglish audio.
  3. Speech output: first try Windows built-in Hindi voices / browser speech synthesis. Local neural TTS can use more memory and setup.
  4. Knowledge search: a small multilingual embedding model, only if your app needs document retrieval.
  5. PC control: model output must go through a permission-checked tool layer; never execute arbitrary shell commands directly from model text.

For an online-first assistant, a remote API can provide stronger reasoning without loading a large LLM locally, but requires internet and provider-specific free-tier limits. This catalog is a model shortlist, not a benchmark. Check license, quantization file size, context memory, and real tokens/second before committing.
